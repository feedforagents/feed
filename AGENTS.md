# Feed contributor instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) and the [branch README](README.md).
Before opening a PR, show that the bug occurs in a supported flow or cite the
maintainer-approved requirement. Run the matching checks from `package.json`
and record their exact results and proof at the PR commit. Attach real runtime
logs for non-UI work, video for a UI fix, comparable benchmarks for performance
and physical-device results for device-dependent changes.

We close submissions with no evidence of a useful change or with unsupported
complexity for highly unlikely paths. Slop.cash contributors lose points under
the applicable policy.
